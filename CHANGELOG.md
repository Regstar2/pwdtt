## v1.8.1 — 2026-09-07

### Исправлено

- Windows VK-авторизация через Microsoft Edge больше не завершается ошибкой только из-за завершения launcher-процесса Edge.
- Browser auth flow после подключения к Chrome DevTools Protocol отслеживает фактическое CDP/WebSocket-соединение.
- Добавлены regression-тесты для Edge process handoff.
